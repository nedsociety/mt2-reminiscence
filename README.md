# Monster Train: Reminiscence

A Monster Train 2 mod that brings Monster Train 1 content into Monster Train 2. It reads that content from a local Monster Train 1 install and does not ship the recordings or other ripped assets.

The first slice is field and boss music. Field themes join the existing ring pool. Boss themes are coin-flipped against the Monster Train 2 theme for that boss. The Last Divinity theme is offered only when that downloadable content is installed.

Music extraction uses the FMOD Engine by Firelight Technologies Pty Ltd.

## Long-term goals

Ship and harden in this order:

1. Music
2. Bosses
3. Alcove events
4. Enemies

When The Last Divinity is installed, also bring over its pacts, pact locations, and the alternate Ring 9 boss. Players without that downloadable content never see or load those assets.

This project is vibe coded without much effort of human reviews.
