# Monster Train: Reminiscence

Plays Monster Train 1 field and boss music during Monster Train 2 runs. The mod reads music from a local Monster Train 1 install. It does not ship those recordings.

Leave **MT1 Path** empty to autodetect the install, or set that directory yourself. A path change applies on the next launch.

**MT1 Boss Musics** coin-flips an MT1 boss theme against the Monster Train 2 theme for that boss. Turn it off and those fights keep the Monster Train 2 theme. The change applies on the next battle.

The Last Divinity theme is offered only when that downloadable content is installed.

Options live in `BepInEx/config/com.reminiscence.mod.cfg`.

Music extraction uses the FMOD Engine by Firelight Technologies Pty Ltd.
